## Distribution limits

This is a signed local Mac build. **Apple notarization was not performed**, because the notarization credentials are not configured. Public downloads still need notarization and a clean-machine distribution check. No Windows or Intel Mac release is claimed here. The optional Intel packaging branch was stopped once the requested arm64 artifacts were complete; the build configuration now lets the explicit CLI architecture control future Mac builds.

The image key stays only in the previously approved project `.env.local`; the profile holds a nonsecret pointer to that exact path. No credential values are in these receipts or the application bundle. If that project file moves, reconnect through Settings. Profile files were backed up inside the existing profile before the installation metadata change.
